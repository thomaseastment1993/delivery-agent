# issue-triage

## Purpose
Fast, consistent issue prioritisation.

## When to use
- New issue or overdue issue

## Inputs
- Issue description and impact

## Process
1. Assess impact on scope/time/cost/benefit.
2. Assign severity and owner.
3. Set target date and escalation path.

## Output
Triaged issue entry and escalation recommendation.
