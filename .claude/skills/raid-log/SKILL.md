# raid-log

## Purpose
Single, consistent way to record RAID items.

## When to use
- Any new risk, assumption, issue or dependency

## Inputs
- Entry details (description, owner, date)

## Process
1. Assign next ID per conventions.
2. Record in the right file under `project-data/raid/`.
3. Cross-link related items.

## Output
Updated RAID files.

## References
Follow `../_shared/conventions.md`. Add supporting material to `references/`.
