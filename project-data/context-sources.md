# Context Sources

Use this index to find supporting project context held outside the project's managed records. `project-data/` remains the source of truth for current project state; linked sources provide evidence or background and do not replace the project records.

## How to use this index

- Add one row per useful source. Use a descriptive name and a direct link to the document, folder, ticket, or system view.
- State what the source is authoritative for, if anything. Do not treat every linked source as equally authoritative.
- Record access requirements and confidentiality handling. Do not put credentials, access tokens, or confidential content in this index.
- Update `Last verified` when checking that a link works and its content is current. Use `YYYY-MM-DD`; use `Unknown` if it has not been checked.
- Read a source only through tools and permissions available in the current environment. A URL alone does not grant access. If a source cannot be opened, say so and request an accessible copy or connector rather than guessing.
- When linked information conflicts with `project-data/` or another source, flag the conflict and identify the source and date; do not silently overwrite managed project records.
